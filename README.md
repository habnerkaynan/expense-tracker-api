# Expense Tracker API

A REST API for tracking personal expenses, built with FastAPI and SQLModel.

**Live demo:** [expense-tracker-api-121r.onrender.com/docs](https://expense-tracker-api-121r.onrender.com/docs)

> Hosted on Render's free tier. The first request after a period of inactivity may take up to a minute while the server wakes up.

## Features

- Create, read, update and delete expenses (full CRUD)
- Filter expenses by category and date range
- Summary endpoint with total spent and number of expenses
- Input validation (e.g. amounts must be greater than zero)
- Automated tests with pytest
- Interactive API documentation generated by FastAPI

## Tech stack

- **Python** 3.14
- **FastAPI**: web framework
- **SQLModel**: database models and queries
- **SQLite**: database
- **pytest**: automated tests
- **Render**: deployment

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/expenses` | List expenses (optional filters: `category`, `start`, `end`) |
| POST | `/expenses` | Create an expense |
| GET | `/expenses/summary` | Total spent and number of expenses |
| GET | `/expenses/{id}` | Get one expense |
| PUT | `/expenses/{id}` | Update an expense |
| DELETE | `/expenses/{id}` | Delete an expense |

### Example request

```json
POST /expenses
{
  "description": "Groceries",
  "amount": 45.90,
  "category": "Food",
  "spent_on": "2026-10-09"
}
```

## Running locally

```bash
git clone https://github.com/habnerkaynan/expense-tracker-api.git
cd expense-tracker-api
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
fastapi dev main.py
```

Then open http://127.0.0.1:8000/docs

## Running tests

```bash
pytest
```
